## Structure Conventions
1. All backlog stories follow consistent naming: `Story [ID] [Description].md`
2. ID numbering indicates feature area:
   - 10s: Infrastructure
   - 20s: Subscriptions
   - 30s: Virtual Economy
   - 40s: Predictions
   - 50s: Rewards
   - 60s: AI Features
   - 70s: Community
   - 80s: News
3. Special planning stories use `XX` placeholder in ID
